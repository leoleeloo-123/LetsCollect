# Legacy Color Dog implementation archive

Status: retired from the active Color Animals pool on 2026-07-22.

This folder retains obsolete masks, builders, and implementation studies. The
geometry later used by Diamond Dog is now fully offline under
`assets/models/archive/diamond-dog/`; no Diamond or generic Color Dog runtime is
served by the active frontend.

Restoration requires a new explicit model identity, a current source/runtime
pipeline, catalog and type registration, validated recolor masks, and mobile QA.
