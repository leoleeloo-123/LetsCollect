# Diamond Dog archive

Status: archived on 2026-07-27 because the crystal treatment no longer matches
the current Color Animals direction.

- `source/` keeps the original high-resolution GLB and import notes. Source GLBs
  remain local and Git-ignored.
- The compact runtime remains at
  `public/models/toys/diamond-dog/model-mobile-v001.glb` only so previously
  collected local items and the internal Lab can still render.
- The model is not a member of an active Collect series and is no longer
  generated by the legacy `/draw` route.

To restore it, move the source folder back to
`assets/models/source/diamond-dog/`, re-register the special-exhibit draw branch,
and revalidate the crystal material on mobile.
