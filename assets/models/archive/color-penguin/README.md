# Retired Color Penguin assets

The active replacement is Color Penguin v003. It keeps the stable
`color-penguin` ID and Lab route, and only recolors the source-pink earmuff top
and cup.

## v001

v001 included a scarf whose shared UV and geometry boundaries could not be
recolored reliably. Its source, runtime, masks, builder, and final Lab code are
stored in the original `source/`, `runtime/`, `mask-builders/`, and `code/`
folders in this archive.

## v002

v002 removed the scarf but still had visible source-color seams around the cup
and earmuff top. Its complete source, runtime, masks, builder, notes, and Lab
code snapshot are stored under `v002/`.

Nothing in this archive is requested by the active frontend.
