# Color Bird archive

The retired 2026-07-19 Color Bird recolored the body, cap, and blush through a
multi-channel texture mask plus semantic geometry protection. It was replaced
on 2026-07-29 by the crown-only `model-source-v002.glb` workflow.

- `source/model-source-v001.glb` is the retired high-resolution input.
- `runtime/model-mobile-v001.glb` is the retired 310,308-byte browser runtime.
- `masks/protect-mask-mobile-v001.webp` through `v014.webp` are the retired
  validation and production masks.
- `masks/head-zone-v001.webp` is a historical zone experiment.
- `mask-builders/` contains the retired v001-v005, v011, and v014 builder chain.
- `code/full-body-zones-v1/` preserves the retired Lab viewer, page, semantic
  geometry helper, shader, styles, and production material implementation.

No file in this directory is requested by the browser.
