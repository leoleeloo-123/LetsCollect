# Archived 3D Experiments

Retired model experiments live here for local research only. They are never
browser-served and must not be referenced by production model URLs.

Git tracks each model's top-level `README.md` manifest. Source GLBs, runtime
files, masks, builders, and implementation snapshots are intentionally ignored
so the repository remains deployable and the archive does not become a second
production asset tree.

- `color-bird/`: retired v001 full-body recoloring model and shader history.
- `color-penguin/`: superseded v001 and v002 scarf/asset studies.
- `color-teddy/`: retired cream teddy test model and its dedicated rendering path.
- `color-dog/`: superseded generic dog masks and implementation studies.
- `color-unicorn/`: abandoned recoloring experiment.
- `diamond-dog/` and `diamond-unicorn/`: archived crystal studies.
